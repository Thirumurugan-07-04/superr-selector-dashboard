# Upload without folders

You can upload every file on the main GitHub repository page. Do not create a `data` folder.

Upload these files beside each other:

1. `streamlit_app.py`
2. `rr_style.css`
3. `requirements.txt`
4. `pressure_states.csv.gz`
5. `pressure_report.json`
6. `batter_board.csv`
7. `bowler_board.csv`

The repaired `streamlit_app.py` accepts this simple layout. It also accepts the older `data`-folder layout, so any old folder can remain without causing a problem.
